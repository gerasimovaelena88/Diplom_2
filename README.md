# Diplom_2

Тест test_create_order_without_auth выявляет критический баг на стороне бекэнда. API позволяет создавать заказы без авторизации, хотя документация требует авторизации и фронтенд блокирует эту возможность.
Ожидаемое поведение: 401 Unauthorized.
Фактическое поведение: API возвращает 200 OK и создает заказ без проверки авторизации.
Последствия:
    - Обход клиентских ограничений
    - Уязвимость безопасности
    - Нарушение бизнес-логики
